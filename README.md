# 🚦 Intelligent Traffic Control Simulator (Ақылды бағдаршам симуляторы)

«AI Fundamentals» пәні бойынша қорытынды жоба. Симулятор көше қиылысындағы бағдаршамды басқарудың үш тәсілін бірдей трафик жағдайында салыстырады:
1. **Ручное (Фиксированный цикл)** — тұрақты таймер бойынша жұмыс істейтін стандартты бағдаршам.
2. **Hill Climbing (Local Search)** — орташа күту уақытын азайту үшін жасыл фазалардың оңтайлы ұзақтығын іздейтін локалды іздеу алгоритмі.
3. **Q-learning (Reinforcement Learning)** — кезек ұзындығы мен трафик режиміне қарап нақты уақытта фазаны ұстау немесе ауыстыру туралы шешім қабылдайтын агент.
4. **HMM (Hidden Markov Model)** — жылдамдық пен тығыздық датчиктерінің шулы деректері бойынша жолдағы жасырын режимді (*Свободно / Час пик / Пробка*) анықтайды.

---

##  Жоба құрылымы / Структура проекта

- `app.py` — Streamlit негізіндегі негізгі симулятор, алгоритмдер (Hill Climbing, Q-learning, HMM) және интерактивті графиктер.
- `traffic_view.html` — қиылыстағы көлік қозғалысы мен бағдаршамдардың жұмысын көрсететін автономды HTML-визуализация.
- `requirements.txt` — қажетті Python кітапханаларының тізімі.

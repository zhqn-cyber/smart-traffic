# 🚦 Intelligent Traffic Control Simulator (Ақылды бағдаршам симуляторы)

«AI Fundamentals» пәні бойынша қорытынды жоба. Симулятор қиылыстағы бағдаршамды басқарудың үш тәсілін бірдей трафик жағдайында салыстырады, ал төртінші әдіс (HMM) трафиктің жасырын режимін анықтайды:

1. **Қолмен басқару (тұрақты цикл)** — тұрақты таймермен жұмыс істейтін стандартты бағдаршам. Басқа әдістер осымен салыстырылады.
2. **Hill Climbing (Local Search, 3-апта)** — орташа күту уақытын азайту үшін жасыл фазалардың оңтайлы ұзақтығын іздейтін жергілікті іздеу алгоритмі.
3. **Q-learning (Reinforcement Learning, 5-апта)** — кезек ұзындығы мен трафик режиміне қарап, нақты уақытта фазаны ұстап тұру немесе ауыстыру туралы шешім қабылдайтын агент.
4. **HMM (Hidden Markov Model, 6-7-апта)** — жылдамдық пен тығыздық датчиктерінің шулы деректері бойынша жолдағы жасырын режимді (*Бос жол / Қарбалас сағат / Кептеліс*) анықтайды. Бұл баға Q-агентке көмекші ақпарат болады.

## Орнату және іске қосу

Python 3.9 немесе одан жаңа нұсқасы керек.

### 1. Репозиторийді жүктеп алу
```bash
git clone <РЕПОЗИТОРИЙ_СІЛТЕМЕСІ>
cd traffic
```
Git болмаса, `app.py` және `requirements.txt` файлдарын бір қалтаға салып, сол қалтада терминал ашыңыз.

### 2. Виртуалды орта жасау (міндетті емес, бірақ ұсынылады)
```bash
python -m venv venv
```
Іске қосу:
- Windows: `venv\Scripts\activate`
- macOS / Linux: `source venv/bin/activate`

### 3. Тәуелділіктерді орнату
```bash
pip install -r requirements.txt
```
Немесе қолмен: `pip install streamlit pandas numpy plotly`

### 4. Қосымшаны іске қосу
```bash
streamlit run app.py
```
Браузерде `http://localhost:8501` беті ашылады. Ашылмаса, осы мекенжайды браузерге қолмен енгізіңіз.
Егер `streamlit` командасы табылмаса: `python -m streamlit run app.py`

Тоқтату: терминалда `Ctrl+C`.

## Қолдану

1. Сол жақ панельде параметрлерді таңдаңыз (немесе әдепкі мәндерді қалдырыңыз).
2. **«▶️ Симуляцияны іске қосу»** батырмасын басыңыз. Бірінші іске қосу бірнеше секунд алады (Q-агентті оқыту).
3. Нәтижені қосымшалардан (вкладкалардан) қараңыз.

### Параметрлер (бүйір панель)

| Параметр | Мағынасы |
|---|---|
| Кіріс ағынының қарқындылығы | Бір жолаққа минутына неше көлік келеді |
| Бағыттағы жолақ саны | Әр бағыттағы жолақ саны (1–4) |
| Жүктеме қатынасы NS : EW | Бір бағыт екіншісінен қанша есе көп жүктелген |
| Трафик режимінің орташа ұзақтығы | «Бос жол / қарбалас сағат / кептеліс» режимі орта есеппен неше минут тұрады |
| Датчиктер шуы | Датчиктердің қателігі; үлкен болса, HMM-ге қиынырақ |
| Симуляция қадамы, Ұзақтығы | Шешім қабылдау қадамы және симуляцияның жалпы ұзақтығы |
| Сынақ сценарийлерінің саны | Әдістер неше кездейсоқ «күнде» тексеріледі (статистика үшін) |
| Тұрақты циклдегі жасыл | Қолмен басқарудағы жасыл жану уақыты |
| Hill Climbing: іске қосу саны | Алгоритм неше рет қайта басталады |
| Q-learning: эпизодтар, α, γ | Оқыту ұзақтығы, оқыту жылдамдығы, дисконт |
| Агент күйінде HMM бағасын пайдалану | Q-агент HMM болжамын пайдаланады ма |

### Қосымшалар (вкладкалар)

- **🚗 Жол (көрнекі)** — үш қиылыстың анимациясы: кезектер, бағдаршам түстері, өтіп жатқан көліктер. Бұл бөлім оқытушыға нәтижені көзбен көрсету үшін.
- **📊 Салыстыру** — орташа күту уақыты, өткізу қабілеті, кезек графиктері, бағдаршам фазалары.
- **🧗 Hill Climbing (3-апта)** — мақсат функциясының ландшафты мен іздеу траекториялары.
- **🤖 Q-learning (5-апта)** — оқыту қисығы және агент үйренген саясат картасы.
- **🌫️ HMM (6-7-апта)** — шулы датчиктер, нақты және бағаланған режим, ықтималдықтар.
- **📖 Түсініктемелер** — модель мен әдістердің қысқаша сипаттамасы.

## Модель қалай жұмыс істейді

- Қиылыста екі фаза бар: 0 — NS (солтүстік-оңтүстік) жасыл, 1 — EW (шығыс-батыс) жасыл.
- Көліктердің келуі пуассондық; қарқындылық трафиктің жасырын режиміне байланысты (бос жол ×0.6, қарбалас сағат ×1.0, кептеліс ×1.5).
- Жасыл кезінде бір жолаққа секундына 0.5 көлікке дейін өтеді; фазаны ауыстыру 3 секунд жоғалған уақытқа түседі; жасылдың ең аз ұзақтығы — 10 секунд.
- Орташа күту уақыты Литтл заңы бойынша есептеледі: кезекте жиналған көлік-секундтар / келген көліктер саны.

## Нәтиже мысалы

Әдепкі параметрлерде (2 жолақ, 60 минут, 8 сценарий) бір көліктің орташа күту уақыты шамамен:

| Әдіс | Орташа күту, с |
|---|---|
| Қолмен басқару | ~26–28 |
| Hill Climbing | ~15 |
| Q-learning | ~11–13 |

Нақты сандар кездейсоқ сценарийлерге байланысты сәл өзгеріп отырады. HMM режимді шамамен 98% дәлдікпен анықтайды (бір көрсеткішке қарайтын аңғал әдіс — шамамен 81%).

## Шектеулер

- Бір қиылыс, екі фаза; бұрылыстар мен жаяу жүргіншілер ескерілмеген.
- Деректер нақты қаладан емес, модельден алынған.
- Q-learning кестелік әдіс болғандықтан, өте жоғары жүктемеде (қиылыс қатты шамадан тыс жүктелгенде) нашарлайды; мұнда Hill Climbing жақсы жұмыс істейді. Болашақта Deep Q-learning қолдануға болады.
